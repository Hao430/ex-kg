# 枝想 AI 深度思维探索工作台 - 产品需求规格说明书 (PRD)

---

## 1. 产品定位与核心价值

### 1.1 产品概述
**枝想**（深度思维探索工作台）是一款面向**学者、研究人员、架构师、深度自学者与创作者**的**生产级无限画布 AI 对话与知识沉淀工作台**。它彻底打破了传统 AI 聊天软件的“单线程垂直滚屏”限制，以二维空间拓扑结构承载人类非线性的发散思考、因果追问与知识网络。

### 1.2 解决的核心痛点与差异化优势

**差异化定位（结构级）**：枝想不是「又一个 AI 聊天工具」，而是一张**学术级深挖 + 溯源有据**的思维工作台。我们的叙事收敛为一句话：**让每一次追问都逐层下钻、让每一句结论都有据可查**。

差异化分两层：

- **结构级壁垒（留存引擎）——内容资产沉淀**：用户在枝想中积累的不是聊天流水，而是结构化的思维树（节点层级 + 溯源 + 公式）。画布越多、深挖越深，重建成本越高；二期「标签 + 全文检索」将把积累从「存起来」升级为「用得上」，这是产品唯一的结构级留存引擎（详见里程碑二期排期与留存论证）。
- **功能级优势（竞品最难平移的组合）**：**划词分支 × 来源角标 × 学术级公式渲染（LaTeX）** 三件套——单项功能竞品一个迭代周期即可抄平，但这组能力互相咬合（划词出分支、分支带溯源、溯源含公式），共同嵌入深挖工作流，平移成本远高于单项复刻。

| 维度 | 传统线性 AI 助手 | 枝想 画布式深度工作台 |
| :--- | :--- | :--- |
| **学术级深挖** | 单线程对话，追问子问题会污染主线，深挖三层即失焦 | **无损划词分支**：选中任意结论/术语一键生成子议题，问题树逐层下钻，主干永远清晰 |
| **溯源有据** | 答案无出处，幻觉难核验，学术场景不可用 | **来源角标逐句锚定**：AI 结论附带可点击来源；**学术级 LaTeX 公式排版**（行内/块级/矩阵）开箱即用 |
| **知识沉淀（资产留存）** | 聊天记录散乱、不可检索，更换工具即全部弃置 | **画布即知识库**：画板/节点云端沉淀，可导出 JSON/Markdown/PNG 备份；二期标签 + 全文检索让积累可复用 |
| **全局视野** | 一维时间轴，长对话翻查困难，无法横向对比 | **二维拓扑画布**：思考全局与层级脉络空间呈现，多方案并排对比 |
| **海量图谱性能** | 无相关概念 | **超大画布智能优化**：节点折叠、视口虚拟化渲染、超 150 节点自动引导「导出为独立画板」 |
| **工程与商业化** | 多为单机原型，无账号与用量治理 | **生产级全栈**：账号体系与数据严格隔离、画板/节点配额制、VIP 订阅与订单、推演日志审计 |

**用户为什么留下来**（留存逻辑）：
1. **短期**靠深挖体验——划词分支带来的「多挖一层不丢主线」即时价值；
2. **中期**靠成果物——PNG 全景图、Markdown 研报大纲、JSON 备份可直接进入用户的论文/文档工作流；
3. **长期**靠资产沉淀——画布数量与节点深度构成迁移成本，标签 + 全文检索（二期）把迁移成本转化为复用价值。AI 聊天工具迁移成本低的根因是沉淀物为纯文本流水；枝想的沉淀物是结构化思维树，这是留存差异的根本来源。

## 2. 用户画像与典型应用场景

1. **科研学者 / 分析师**：围绕特定前沿课题展开文献调研与因果链论证，针对某学术概念逐段深入追问，保持完整思维树。
2. **软件架构师 / 技术决策者**：针对系统方案进行横向选型（如方案 A vs 方案 B），推演极端异常链路与性能边界，形成结构化架构评审图谱。
3. **内容创作者 / 策略编剧**：构建庞大世界观、推演多线叙事分支走向，多视角角色交互模拟。
4. **终身学习者 / 备考人员**：将庞大知识网络由浅入深层层拆解，遇生僻概念一键分支探索，学完返回主线，不打断系统性理解。

## 3. 核心功能模块规格设计

### 3.1 模块一：无限画布与免拖拽智能树形布局 (Infinite Canvas Engine)
* **画布交互底座**：
  * **平移与缩放**：支持鼠标滚轮、触控板双指缩放（20% ~ 200%），支持空格+拖拽平移视口。
  * **视口控制**：提供一键「自适应居中 (Fit View)」、「100% 重置」与「平滑聚焦运镜」。
  * **点阵参照与微缩导航**：高雅动态点阵背景（Dot Grid）与右下角全局小地图（Minimap）。
* **免拖拽智能布局 (Zero-Drag Auto-Layout)**：
  * 基于拓扑深度递归的水平分层树形布局，自动计算各节点 X/Y 坐标与垂直安全避让距离，杜绝卡片遮挡与重叠。
  * 产生新分支或追问时，系统平滑重排并运镜聚焦至目标卡片。
* **大画布性能保障机制（>150 节点优化）**：
  * **自动检测与性能告警**：当画板节点总数超过 150 个时，界面智能弹出轻量性能优化横幅与分支操作提示。
  * **导出为独立画板 (Branch Off to StoredBoard)**：用户可选择任意子树分支，一键将其及所有关联边完整导出为新的独立画板，并自动从当前主画板移除精简，释放 DOM 资源并加速渲染。

### 3.2 模块二：节点系统与极简沉浸式卡片交互 (Node System)
* **节点类型支持**：
  1. **对话节点 (Chat Node)**：承载用户提示词、AI 流式回答、模型切换器、追问操作等。
  2. **便签/笔记节点 (Note Node)**：用于提炼核心论点、撰写调研摘要或草稿。
* **节点界面人体工学重构（防挤压设计）**：
  * **顶部信息精简**：移除冗余的深度徽标（Depth Badge），精简头部操作区，避免操作按钮在小卡片中发生折叠与换行挤压。
  * **卡片折叠/展开**：单卡一键收起正文，仅保留核心论点标题，快速梳理全图骨架。
  * **多色分类标记**：支持为重要节点标注主题高亮颜色。
  * **富文本排版与代码高亮**：完整支持 Markdown 语法、表格、公式与一键复制；**代码语法高亮列为二期**（一期仅保留代码块样式，不引入高亮库）。

### 3.3 模块三：分支衍生与划词探索 (Branching & Drill-Down)
* **划词钻入兔子洞 (Rabbit Hole)**：
  * 用户选中文本任意段落，自动弹出悬浮工具栏「深入探索 (Branch)」。
  * 自动在右侧创建连线子节点，带入选中文本作为新议题，并保留引用来源标签。
* **祖先链路上下文溯源 (Ancestry Context Resolver)**：
  * 子节点生成时，自动追溯祖先节点的历史问答序列拼接为多轮 Prompt，确保 AI 深刻理解上下文背景。
* **联网搜索与 Grounding 溯源**：
  * 支持一键开启 Google Search 实时联网检索，展示权威来源索引与溯源卡片。

### 3.4 模块四：账户权限与商业化系统 (Auth & Billing)
* **强制登录与多租户 RBAC 权限模型**：
  * **体验版 (User)**：最多 **3 个画板**，每个画板最多 **10 个 AI 推理节点**（合计 30 次生成上限），**不设**日调用上限。
  * **VIP 会员 (VIP)**：画板与 AI 推理节点数量**无限**，享受高优先级响应队列（更高的并发限流阈值），可访问 `is_vip_only` 标记的高级模型。
  * **系统管理员 (Admin)**：全局管理看板、用户启停、VIP 天数赠送、订单查看、AI 全局提示词与模型路由管理。
  * **配额强制下沉服务端**：画板数量、AI 节点数量、子分支导出、模型白名单四类权益限制全部由后端中间件校验，前端仅按服务端返回的状态渲染文案，直连 API 无法绕过。
* **邮箱验证（强制，2026-09 重设计：验证码先行）**：
  * 注册需先获取 6 位数字邮箱验证码（10 分钟有效，连错 5 次作废；发送限流每邮箱 60 秒冷却 + 每 IP 5 次/小时），输码提交并通过校验后才创建账号，账号注册完成即视为邮箱已验证。
  * 已注册邮箱不可重复发送验证码（409）；admin 换绑邮箱后账号回到未验证态，通过 24 小时有效一次性令牌链接完成二次验证，验证邮件可重发（限流 3 次/10 分钟/账号），未验证账号推理请求返回 403。
  * 事务邮件通过 Nodemailer 发送（生产环境 SMTP，开发环境落 Mailpit 本地查看）。
* **账号注销（软删除 + 30 天冷却）**：
  * 用户可在前端账号入口自助注销：账号立即软删除并踢下线全部会话，写入审计日志。
  * 注销后 30 天冷却期内，同邮箱不可注册新账号；管理员可在冷却期内恢复账号（同邮箱冲突时返回 409）。
  * 冷却期超时后账号被硬删除，画布等关联数据级联清除（管理员账号豁免自动硬删）。
* **VIP 到期语义（硬锁定）**：
  * 到期即禁止 AI 推理与新建画板。
  * 必须保留用户带走成果的能力：只读浏览、编辑便签笔记、导出 JSON 与 Markdown 大纲全部放行。
  * 配套到期前提醒横幅与 **7 天宽限期**：宽限期内体验不中断、仅顶部横幅提醒，超期后进入硬锁定。
* **订阅套餐与定价**：
  | 套餐 | 价格 | 时长 |
  | :--- | :--- | :--- |
  | 周度 Pro 会员（周卡） | ¥9.9 | 7 天 |
  | 月度 Pro 会员（月卡） | ¥24.9 | 30 天 |
  | 年度 Pro 会员（年卡） | ¥199 | 365 天 |
* **支付与开通路径**：
  * 一期**不接**真实支付：定义 `PaymentProvider` 抽象（`createOrder` / `queryOrder` / `handleCallback` / `refund`），以 `MockProvider` 跑通 `orders` 全生命周期（pending → paid → 到期）。
  * 一期 VIP 的唯一获取路径为 **Admin 后台赠送**。真实支付渠道（微信 / 支付宝 / Stripe）列入二期。
* **已废弃的能力**：
  * **游客模式**：不再提供，未登录一律 401 并跳转登录页。
  * **算力点数体系**：不再有算力点数、消费流水账本、充值与人工调账；权益统一以画板数与 AI 节点数为口径。

### 3.5 模块五：工程审计 (Observability)
* **AI 推演性能日志 (`ai_request_logs`)**（一期）：
  * 全链路审计每一次大模型调用的响应延迟 (ms)、Token 消耗明细、成功/失败状态与错误栈。
  * 配套自动清理任务（启动即跑 + 每 24 小时执行）：默认保留 90 天（环境变量可配），避免日志无限增长。
* **安全操作审计日志 (`user_audit_logs`)**（一期）：
  * 注册、登录成败、登出、订阅、画布删除、账号冻结/解冻、VIP 赠送/撤销、模型配置等 11 类关键动作全量写入，含操作者、目标对象与 IP。
  * 管理员可在后台分页查询（`GET /api/admin/audit-logs`）；默认保留 180 天（环境变量可配）。

> **二期规划**：快照版本控制 (`canvas_snapshots`)、公开分享与协作凭证 (`canvas_shares`)、模板库 (`canvas_templates`)、标签与全文检索入口 (`tags` / `canvas_tags`)、站内通知 (`notifications`) 均已建表，但一期不启用，详见 [里程碑与分期规划](./里程碑与分期规划.md)。

## 5. 项目验收标准与指标 (KPIs)

1. **数据一致性**：画布关闭、刷新或跨设备重载时，所有节点多轮对话、折叠状态、颜色、便签内容及连线锚点零丢失。
2. **响应性能**：大画布（100+ 节点）平移与缩放保持流畅；>150 节点分支导出独立画板在 500ms 内完成剪切与保存。
3. **商业化闭环**：会员订阅即时生效，画板数与 AI 节点数配额由服务端强制校验，订单流水完整可审计。
4. **模型高可用**：Gemini 与多渠道备选模型自动容灾轮询，极端情况下无感平滑降级。
