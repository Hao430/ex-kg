# RabbitHole.chat 产品需求规格说明书 (PRD)

## 1. 产品定位与核心价值

### 1.1 产品概述
**RabbitHole**（灵感源自《爱丽丝梦游仙境》中的“兔子洞”隐喻）是一款面向**深度思考、研究探索与发散性创意**的**无限画布 AI 对话工作台**。它打破了传统 AI 聊天软件的单一线性时间轴限制，让用户的思维以非线性的方式自由流淌、分叉与蔓延。

### 1.2 解决的核心痛点
| 传统线性 AI 对话 (如 ChatGPT/Claude) | RabbitHole 画布式对话 |
| :--- | :--- |
| **一维单线滚屏**：长会话易迷失，上文翻找困难 | **二维空间排布**：空间记忆，全局脉络一览无余 |
| **分支代价高**：探讨分支子话题会污染主对话上下文 | **无损分支 (Branching)**：随时从任意节点/文本切出子话题，保留母体脉络 |
| **多角度对比难**：无法直观横向对比同一问题的不同解法 | **并行对比**：在同一画布上并排生成多个解答与模型输出 |
| **思维沉淀弱**：聊天记录难以直接转化为结构化知识产出 | **知识图谱化**：从发散讨论、追问溯源到沉淀笔记一体化 |

## 2. 用户画像与典型场景

1. **研究员 / 学者 / 分析师**：围绕复杂课题展开树状调研，针对论文摘要逐段深挖追问，保持文献与思考链的完整空间结构。
2. **产品经理 / 架构师**：做技术方案选型（对比方案 A vs 方案 B）、头脑风暴并拆解系统架构与功能树。
3. **内容创作者 / 编剧**：世界观设定、故事剧情走向分支推演、多角色视角模拟。
4. **自学者 / 开发者**：学习复杂概念时，遇到生词或公式即时拉出独立子节点专项讲解，学完回到主干，不再打断主思路。

## 3. 核心功能模块详细设计

### 3.1 模块一：无限画布引擎 (Infinite Canvas Engine)
* **画布交互**：
  * **平移 (Pan)**：按住空格键+拖拽、鼠标中键拖拽，或在空白处直接拖拽。
  * **缩放 (Zoom)**：滚轮缩放（支持 20% ~ 200% 动态缩放），支持一键“自适应画布 (Fit View)”与“100% 重置”。
  * **背景视效**：细腻点阵网格（Dot Grid），随缩放动态微调间距，提供空间参照。
  * **微缩导航 (Minimap)**：右下角小地图，高亮当前视口位置，支持点击快速跳转。

### 3.2 模块二：节点系统与免拖拽智能布局 (Node System & Zero-Drag Auto-Layout)
* **设计哲学（免拖拽 Zero-Drag）**：
  * **无需手动拖拽对齐**：传统白板需要用户不断挪动卡片、收拾杂乱版面，极度耗费认知心智。RabbitHole 采用**自动化分层树状/DAG 智能布局算法**，自动计算最优坐标与层级间距，保证全图始终整洁有序、永不重叠。
  * **聚焦视口跟随**：产生新分支时，画布视口自动平滑运镜聚焦到新节点，提供沉浸式探索流。
* **节点类型**：
  1. **对话节点 (Chat Node)**：包含用户 Prompt、AI 回答、模型切换器、重试/分支按钮。
  2. **笔记/摘要节点 (Note Node)**：富文本/Markdown 便签，用于提炼结论、撰写总结。
  3. **参考源节点 (Source Node)**：嵌入参考链接、片段摘要、数据卡片。
* **节点操作**：
  * 自适应内容高度、折叠/展开、一键复制内容、删除节点、快速展开子分支。
  * **节点状态**：闲置、生成中（流式光标与骨架渐变）、激活/选中（高亮边框与父子链路溯源）。

### 3.3 模块三：分支与思维连线 (Branching & Connectors)
* **“钻入兔子洞 (Go Down The Rabbit Hole)”**：
  * **划词分支**：用户在 AI 回答中选中某段文字，弹出悬浮菜单「🐰 深入探索 (Branch)」，自动以选中文本为新问题，在右侧生成连线子节点。
  * **节点分支**：点击节点右侧/底部的加号 `+`，衍生出关联的子对话卡片。
* **动态贝塞尔连线**：
  * 优雅的贝塞尔平滑曲线连接父子节点，带指示箭头。
  * 悬停高亮完整思考链路（祖先路径与子孙路径）。

### 3.4 模块四：上下文继承与 AI 交互 (Context & AI Engine)
* **智能上下文链**：
  * 子节点在向 AI 发送请求时，自动组装**祖先节点的问答历史**，确保逻辑连续性。
  * **上下文范围配置**：支持“继承全部祖先脉络”、“仅继承直接父节点”或“独立全新上下文”。
* **流式生成 (Streaming Markdown)**：
  * 支持代码块高亮、数学公式、表格、加粗等标准 Markdown 解析。
  * 停止生成、重新生成、多模型切换（Gemini 2.5 Flash / Gemini Pro 等）。

### 3.5 模块五：画板管理与本地持久化 (Board & Storage)
* **本地优先 (Local-First)**：数据存储在本地（LocalStorage / IndexedDB），保护隐私且加载即开。
* **多画布支持**：创建、重命名、切换多个研究项目画布。
* **导入与导出**：
  * 导出为 JSON（画布完整备份与恢复）。
  * 导出为 Markdown（将整棵思考树拍平为结构化大纲）。
  * 导出为画布高清图片。
* **预置模板库**：提供“深度研报树”、“方案对比图”、“头脑风暴散落卡”等开箱即用模板。

## 5. 核心数据结构设计 (TypeScript)

```typescript
// 画布节点
export interface CanvasNode {
  id: string;
  type: 'chat' | 'note' | 'source';
  x: number;
  y: number;
  width: number;
  title: string;
  parentId?: string; // 父节点 ID
  messages: Array<{
    role: 'user' | 'assistant';
    content: string;
    timestamp: number;
  }>;
  contextMode: 'ancestors' | 'parent_only' | 'none';
  status: 'idle' | 'generating' | 'error';
  color?: string;
  isCollapsed?: boolean;
}

// 连线关系
export interface CanvasEdge {
  id: string;
  sourceNodeId: string;
  targetNodeId: string;
  label?: string; // 触发分支的关键概念/短语
}

// 画布整体状态
export interface RabbitBoard {
  id: string;
  name: string;
  updatedAt: number;
  viewport: { x: number; y: number; zoom: number };
  nodes: CanvasNode[];
  edges: CanvasEdge[];
}
```

## 6. 实施落地规划 (Implementation Phases)

* **Phase 1: 核心画布与节点交互**
  * 构建可无限平移、缩放的点阵画布引擎。
  * 实现节点创建、拖拽、定位、自适应高度。
  * 搭建 SVG 贝塞尔曲线连接器，自动追踪节点移动。
* **Phase 2: 对话与分支链路**
  * 对接 Gemini API 流式输出与 Markdown 解析。
  * 实现“节点延伸分支”和“文本选中一键追问（Rabbit Hole）”。
  * 实现祖先链路上下文拼接与流式生成。
* **Phase 3: 体验打磨与持久化**
  * 便签节点 (Note Node) 与混合画布支持。
  * 画布小地图 (Minimap)、缩放控制器、快捷键支持。
  * 多画布管理、本地存储自动保存、导出 JSON / Markdown 功能。
