# Spec F1 — 找回密码

> 来源：`docs/里程碑与分期规划.md` F 组 F1；复用 D3 的 mailer 与 token 模式
> 状态：本轮实施

## 1. 设计

**数据模型**：users 迁移追加 `reset_token VARCHAR(64)`、`reset_expires_at TIMESTAMPTZ`（1 小时有效）+ 索引。

**流程**：
- `POST /api/auth/forgot-password {email}`：**无论邮箱是否存在恒返回 200**（防账号枚举）；存在则生成 1h token → 发送重置邮件（链接 `${APP_URL||origin}/reset-password?token=`）；限流复用 `signupRateLimiter` 同参数（5 次/小时/IP，独立实例防邮件轰炸）
- `POST /api/auth/reset-password {token, password}`：token 有效（1h 内）→ 更新密码（scrypt）→ 清空 reset_token → **删除该用户全部会话**（踢下线）→ 200；无效/过期 → 400 `INVALID_TOKEN`；password 复用注册规则（≥6 位）

**mailer**：`sendPasswordResetEmail(to, resetUrl)`（干跑 outbox 模式同 D3）。

## 2. 测试先行（`tests/f1-password-reset.test.ts`）

1. 已知邮箱 forgot-password → 200；outbox 含 reset token；响应不泄露邮箱是否存在
2. 未知邮箱 forgot-password → 200 且 outbox 不增加
3. 用 outbox token reset-password → 200；旧密码登录 401、新密码登录 200
4. 无效 token → 400 INVALID_TOKEN
5. 重置后旧会话 cookie → 401（踢下线）
