# Spec A2 — 画布加载改走服务端（服务端为真源）

> 来源：`docs/里程碑与分期规划.md` A 组 A2 工作项、决策 #1；验收「换浏览器或设备登录后，节点、连线、折叠状态、颜色、便签、多轮 messages 零丢失」
> 状态：本轮实施（前端；保存主路径 POST /save 已具备，失败回退本地由 A5 重试队列承担）

## 1. 设计

**storage.ts 新增**：
- `fetchBoardFromServer(boardId)`：GET `/api/canvases/:id` → 映射为 `StoredBoard`（title→name、serverUpdatedAt=updatedAt、viewport/nodes/edges 直传）→ **写本地缓存 + 更新索引**（服务端为真源，不触发入队）；404（从未同步）/网络失败 → `null`
- `fetchBoardListFromServer()`：GET `/api/canvases` → `DeepDiveBoardMeta[]`；失败 → `null`
- saveBoard 内部抽出 `persistBoard()`（纯本地持久化，不入队），saveBoard = persistBoard + enqueue

**App.tsx**：
- `applyLoadedBoard(board)`：统一的画布状态应用
- 启动加载与切换画板改为 async：**已登录 → 服务端优先**（画布详情 + 画板列表），服务端无此画布/失败 → 回退本地
- 未登录 → 维持本地加载（草稿语义，A6 处理合并）

## 2. 测试先行（`tests/a2-server-load.test.ts`，stub localStorage/fetch）

1. 服务端 200 → 返回映射正确的 StoredBoard，本地缓存含 serverUpdatedAt，索引被更新
2. 404 → null，本地不受影响
3. 网络异常 → null
4. fetchBoardListFromServer 200 → DeepDiveBoardMeta[] 映射正确；失败 → null
