# Spec A1 — 删除游客模式，强制登录

> 来源：`docs/里程碑与分期规划.md` 决策 #2（游客模式砍掉）、A1 工作项、验收标准第 1 条
> 状态：本轮实施（后端部分；前端跳转登录页由前端任务跟进，本轮确认前端无 guest 依赖）

## 1. 背景与决策

里程碑已锁定「游客模式砍掉，强制登录」。现状（重构后）仍保留三处游客逻辑：

1. `POST /api/auth/guest` 路由（server/routes/auth.ts）
2. `middleware/auth.ts` 中 authMiddleware 的「无有效 token 自动开户游客」分支
3. `services/auth.service.ts` 的 `provisionGuest()`（两处重复逻辑合并后的唯一实现）

## 2. 目标行为（After）

| 场景 | Before | After |
| :--- | :--- | :--- |
| 未登录 `GET /api/auth/me` | 200（自动建游客号） | **401** `{ error, code: 'UNAUTHORIZED' }` |
| 未登录 `GET /api/canvases` 等受保护端点 | 200（自动建游客号） | **401**，同上 |
| `POST /api/auth/guest` | 201 建游客号 | **404**（路由删除） |
| 无 cookie `POST /api/auth/sign-out` | 200 | 200（不变，幂等） |
| 无登录 `POST /api/auth/feedback` | 201（可选认证） | 201（不变） |
| 有效会话访问受保护端点 | 200 | 200（不变） |
| 冻结账号持有效会话 | 403 ACCOUNT_FROZEN | 403（不变） |

## 3. 改动清单

- `server/routes/auth.ts`：删除 `/guest` 端点与 `provisionGuest` import
- `server/middleware/auth.ts`：authMiddleware 删除自动开户分支；无有效会话一律 `next(new UnauthorizedError())`（由 error-handler 转 401）
- `server/services/auth.service.ts`：删除 `provisionGuest()`
- `server/app.ts`（新增）：从 server.ts 抽出 `createApp()` 工厂（可测试性；路由挂载+errorHandler 归 app，监听归 server.ts）

## 4. 测试先行（测试文件先于实现提交同批）

`tests/a1-guest-removal.test.ts`（node:test + tsx，内存模式）：
1. 未登录 me → 401 且 code=UNAUTHORIZED
2. 未登录 canvases → 401
3. POST /api/auth/guest → 404
4. seed 账号 sign-in → 200；带 cookie me → 200
5. 冻结流程不回归（本 spec 不覆盖，留 A 组后续）

运行：`npm run test`（新增 script：`tsx --test tests/*.test.ts`）。
