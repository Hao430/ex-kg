# Spec A5 — 断网降级 + 重试队列 + 可见保存状态指示

> 来源：`docs/里程碑与分期规划.md` A 组 A5 工作项；验收「断网期间编辑不丢数据，恢复网络后自动补传」「保存失败时前端有明确错误提示」
> 状态：本轮实施（前端）

## 1. 现状

- `saveBoard` 先写 localStorage（断网不丢数据已满足），随后 fire-and-forget 调 `syncBoardToBackend`，失败仅 `console.warn`——无重试、无用户可见状态
- 409 冲突（A4）已有事件 → toast，但无持久状态指示

## 2. 设计

**重试队列 `src/lib/sync-queue.ts`**（框架无关，便于测试）：
- `setSyncExecutor(fn: (boardId) => Promise<'ok'|'conflict'|'fail'>)`：由 storage 注册真实同步
- `enqueue(boardId)`：去重（同画布保留最早尝试计数），状态 `pending`，异步 flush
- flush：依次执行 executor；`ok` → 移除并派发 `saved`；`conflict` → 移除并派发 `conflict`（不重试）；`fail` → 计数 +1，退避重试 `min(2^n×2s, 30s)`，超过 `MAX_RETRIES=5` 移除并派发 `error`
- `window online` 事件 → 立即 flush；`onSyncState(cb)` 供 UI 订阅；`getPendingIds()`；`resetForTest()`

**storage.ts 接线**：
- 模块加载时注册 executor：按 id `loadBoard` → 同步 → `ok` 时把响应 `canvas.updatedAt` 写回本地记录的 `serverUpdatedAt`（不触发再次入队）
- `saveBoard` 的直连同步改为 `enqueueBoardSync(board.id)`

**状态指示 `Topbar`**：
- 新增可选 prop `syncState`：`saved`（已同步，绿）/ `pending`（待同步，灰）/ `error`（同步失败，红）/ `conflict`（版本冲突，黄）；画板名旁小圆点 + title 提示
- `App.tsx` 订阅 `onSyncState` 维护当前画板状态传入

## 3. 测试先行（`tests/a5-sync-queue.test.ts`，mock timers + stub executor）

1. 成功路径：enqueue → ok → 派发 saved，队列清空
2. 失败重试：fail×2 后 ok → 按 backoff 依次执行，最终 saved
3. 超过 MAX_RETRIES → 派发 error，不再重试
4. conflict → 派发 conflict 且不再重试
5. 去重：同 id 重复 enqueue 只保留一个条目
6. online 事件触发 flush（window stub）
