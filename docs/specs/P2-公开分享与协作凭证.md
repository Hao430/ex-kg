# Spec 二期-1 — 公开分享与协作凭证（canvas_shares 激活）

> 来源：`docs/里程碑与分期规划.md` 二期 #2；PRD 3.5「公开分享与协作凭证（只读/克隆、访问次数与有效期校验）」
> 状态：本轮实施（端点先行，分享 UI 前端另起任务）；`password_hash` 字段预留本轮不启用

## 1. 数据模型

`canvas_shares` 表已建（schema.ts）。新增 `ShareRecord`：
`{ id, canvas_id, share_code, permission: 'view'|'clone', views_count, expires_at?: string|null, created_at }`

## 2. 端点

| 方法+路径 | 鉴权 | 说明 |
| :--- | :--- | :--- |
| `POST /api/canvases/:id/share` | authMiddleware | 属主/Admin 创建分享凭证：body `{ permission: 'view'\|'clone', expiresInDays?: number }` → 201 `{ shareCode, url: '/share/:code', permission, expiresAt }`；无权访问该画布 → 403/404 |
| `GET /api/shares/:code` | **公开** | 凭证校验（不存在 404 / 过期 410 GONE）→ `views_count+1` → 返回 `{ permission, expiresAt, viewsCount, canvas }`（画布数据经 admin 语义读取，绕过属主限制） |
| `POST /api/shares/:code/clone` | authMiddleware | `permission='clone'` 才允许（view → 403 `CLONE_NOT_ALLOWED`）→ 复制画布为请求者新画板（新 id `board-<ts>`、标题加「（副本）」、属主=请求者）→ 201 `{ boardId }` |
| `DELETE /api/canvases/:id/share` | authMiddleware | 属主/Admin 撤销分享（删除该画布全部凭证）→ 200 |

- 过期语义：`expires_at` 非空且 ≤ now → 分享视为不存在（GET 410、clone 410）
- `views_count`：每次成功 GET 自增
- 分享码：`randomBytes(8).toString('hex')`（16 位）

## 3. 测试先行（`tests/p2-share.test.ts`）

1. 属主创建 view 分享 → 201 + shareCode；公开 GET（无 cookie）→ 200 含画布数据；两次 GET 后 viewsCount=2
2. view 权限 clone → 403 CLONE_NOT_ALLOWED
3. 创建 clone 分享 → 另一用户 clone → 201 + 新 boardId；GET 新画板（以 clone 者 cookie）→ 数据完整且属主为其本人
4. 过期分享（expiresInDays 传 -1）→ GET 410
5. 非属主对他人画布创建分享 → 403
6. 属主撤销后 → GET 404
7. 未登录 clone → 401
