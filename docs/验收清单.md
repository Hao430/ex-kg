# RabbitHole.chat 验收规格说明书 (SPEC & Acceptance Checklist)

---

## 1. 规范约定与说明 (Conventions)

本验收规范遵循 **RFC 2119** 关键字准则与 **BDD (Behavior-Driven Development) / Given-When-Then** 场景测试规范：
- **[MUST / 强制]**：必须满足的硬性指标，未满足则视为阻断级缺陷 (Blocker)。
- **[SHOULD / 推荐]**：强烈推荐实现的体验细节，确保媲美源站水准。
- **[MAY / 可选]**：高阶增强功能，在核心链路完备后演进。

---

## 2. 功能验收规格清单 (Functional Acceptance Specs)

### SPEC-01: 无限画布视口引擎 (Infinite Canvas & Viewport Engine)

| 编号 | 验收项 | 优先级 | 规格定义 (Given-When-Then 行为规范) | 验收状态 |
| :--- | :--- | :--- | :--- | :--- |
| **AC-01.1** | 平移自由度 (Panning) | **MUST** | **Given** 用户在画布任意空白区域<br>**When** 鼠标左键拖拽、中键拖拽或按住空格拖拽<br>**Then** 画布视口以 1:1 位移平滑移动，无卡顿与跳变。 | [ ] 待验收 |
| **AC-01.2** | 智能滚轮缩放 (Zooming) | **MUST** | **Given** 鼠标悬停在画布任意位置<br>**When** 滚动鼠标滚轮或触控板手势缩放<br>**Then** 画布以当前光标为几何中心平滑缩放，缩放范围约束在 `20% ~ 200%`。 | [ ] 待验收 |
| **AC-01.3** | 矢量点阵背景 (DotGrid) | **MUST** | **Given** 画布在任意缩放比和视口位置<br>**When** 视口位移或缩放<br>**Then** 点阵网格随缩放动态适应间距，提供清晰空间坐标感，无像素断裂。 | [ ] 待验收 |
| **AC-01.4** | 视口归位与适应 (Fit View) | **MUST** | **Given** 画布上分布着若干思考节点<br>**When** 用户点击底部或工具栏的「适应屏幕 (Fit View)」按钮<br>**Then** 视口自动平滑运镜，将全部节点按合适边距居中充满视口。 | [ ] 待验收 |
| **AC-01.5** | 微缩导航小地图 (Minimap) | **SHOULD** | **Given** 节点在画布大面积分布<br>**When** 查看右下角 Minimap<br>**Then** 实时显示节点微缩轮廓与当前屏幕视口红框，点击 Minimap 任意区域可快速跃迁。 | [ ] 待验收 |

### SPEC-02: 免拖拽自动分层树形布局 (Zero-Drag Hierarchical Layout)

| 编号 | 验收项 | 优先级 | 规格定义 (Given-When-Then 行为规范) | 验收状态 |
| :--- | :--- | :--- | :--- | :--- |
| **AC-02.1** | 锁定自由拖拽 | **MUST** | **Given** 任何卡片节点<br>**When** 用户尝试拖动卡片<br>**Then** 节点不可随意拖拉乱序 (`nodesDraggable: false`)，免除用户整理对齐的心理负担。 | [ ] 待验收 |
| **AC-02.2** | 水平深度分层 (X 轴) | **MUST** | **Given** 根节点及多级子孙节点<br>**When** 计算布局坐标<br>**Then** 节点的 X 坐标严格由其所在的思考树深度决定（如 $X = \text{Depth} \times 540$），层级间距整齐划一。 | [ ] 待验收 |
| **AC-02.3** | 垂直动态推移 (Y 轴防重叠) | **MUST** | **Given** 存在多个同级分支卡片，且各卡片 Markdown 内容高度不一<br>**When** 渲染或生成内容拉高卡片高度<br>**Then** 布局算法自动计算下级外接盒高度，同级分支垂直留白恒定（RowGap $\ge 40px$），永不出现重叠。 | [ ] 待验收 |
| **AC-02.4** | 父子节点几何居中 | **MUST** | **Given** 一个父节点拥有多个子分支<br>**When** 布局计算完毕<br>**Then** 父节点的 Y 轴坐标始终居中于其所有直接子节点的垂直中心线。 | [ ] 待验收 |
| **AC-02.5** | 平滑变形过渡 (Transition) | **SHOULD** | **Given** 某个节点展开或折叠子树<br>**When** 布局坐标更新<br>**Then** 全局节点采用平滑贝塞尔补间动画过渡至新坐标，无剧烈突变。 | [ ] 待验收 |

### SPEC-03: 节点系统与对话卡片交互 (Node System Spec)

| 编号 | 验收项 | 优先级 | 规格定义 (Given-When-Then 行为规范) | 验收状态 |
| :--- | :--- | :--- | :--- | :--- |
| **AC-03.1** | 工业级 BaseNode 结构 | **MUST** | **Given** 任意对话卡片<br>**When** 渲染呈现<br>**Then** 符合官方 BaseNode 规范，包含卡片头部（角色/模型/深度标签）、消息体、状态栏与连接端点 Handle。 | [ ] 待验收 |
| **AC-03.2** | 输入与多轮提问 | **MUST** | **Given** 节点底部输入框<br>**When** 用户键入 Prompt 并按 Enter (或点击发送)<br>**Then** 发起提问，输入框自动自适应清空，卡片高度随新消息动态撑开。 | [ ] 待验收 |
| **AC-03.3** | 流式 Markdown 渲染 | **MUST** | **Given** AI 正在生成回答<br>**When** 流式收到 SSE 数据 Token<br>**Then** 实时解析 Markdown，无缝渲染代码高亮、数学公式、列表与加粗，带生成光标指示。 | [ ] 待验收 |
| **AC-03.4** | 节点控制操作 | **MUST** | **Given** 节点处于闲置状态<br>**When** 用户操作右上角菜单<br>**Then** 支持：一键复制全文、折叠/展开、删除本节点（及其级联子树警告确认）。 | [ ] 待验收 |
| **AC-03.5** | 便签随笔节点 (Note Node) | **SHOULD** | **Given** 工具栏点击「添加笔记」<br>**When** 在空白处创建便签<br>**Then** 生成纯 Markdown 记录节点，用于提炼核心论点，支持与对话节点连线。 | [ ] 待验收 |

### SPEC-04: “钻入兔子洞”划词分支与连线拓扑 (Rabbit Hole Branching & Edges)

| 编号 | 验收项 | 优先级 | 规格定义 (Given-When-Then 行为规范) | 验收状态 |
| :--- | :--- | :--- | :--- | :--- |
| **AC-04.1** | 划词探测与悬浮菜单 | **MUST** | **Given** AI 回答生成的 Markdown 文本<br>**When** 用户使用鼠标划选某词句或概念<br>**Then** 原生选区被精确捕获，在选中文本正上方弹出悬浮胶囊按钮「🐰 钻入兔子洞 (Branch)」。 | [ ] 待验收 |
| **AC-04.2** | 一键创建深入子节点 | **MUST** | **Given** 弹出划词悬浮胶囊<br>**When** 用户点击「钻入兔子洞」<br>**Then** 1. 自动在父节点右侧计算安全空位生成子节点；<br>2. 自动填入以选词为主题的追问提示；<br>3. 视口平滑运镜对齐新节点。 | [ ] 待验收 |
| **AC-04.3** | 节点级衍生分支按钮 | **MUST** | **Given** 卡片右侧边缘的加号 `+` 连接锚点<br>**When** 用户点击加号<br>**Then** 从当前节点衍生一个全新的通用平行子分支。 | [ ] 待验收 |
| **AC-04.4** | 动态平滑贝塞尔连线 | **MUST** | **Given** 父子节点连接关系<br>**When** 渲染 SVG 连线<br>**Then** 生成自然流畅的三次贝塞尔曲线 (`BezierEdge`)，末端带方向指示箭头 (`ArrowClosed`)。 | [ ] 待验收 |
| **AC-04.5** | 思维链路溯源高亮 | **SHOULD** | **Given** 任意子节点被聚焦或点击<br>**When** 激活高亮状态<br>**Then** 该节点的整条向上祖先链路（从根到此节点的所有 Edge 和 Node）整体高亮发光，突出思考主干。 | [ ] 待验收 |

### SPEC-05: AI 引擎与祖先上下文溯源 (AI Engine & Ancestry Context)

| 编号 | 验收项 | 优先级 | 规格定义 (Given-When-Then 行为规范) | 验收状态 |
| :--- | :--- | :--- | :--- | :--- |
| **AC-05.1** | 祖先链路完整上下文组装 | **MUST** | **Given** 处于第 N 层级的子分支节点<br>**When** 用户在子节点中发送提问<br>**Then** 系统沿 DAG 有向边递归向上追溯全部祖先对话，组装为结构完整的多轮历史发送给 Gemini，保证逻辑不失真。 | [ ] 待验收 |

## 3. 非功能验收规格 (Non-Functional Requirements)

| 指标维度 | 标准要求 | 检验方法 |
| :--- | :--- | :--- |
| **渲染流畅度 (FPS)** | 画布平移、缩放与动画帧率 $\ge 60\text{FPS}$ | Chrome Performance 录制，无严重掉帧与主线程阻塞 |
| **无布局抖动 (CLS)** | 节点卡片内容增多撑高时，仅平滑向下推移兄弟节点，页面整体无突发跳跃 | 观察动态布局重排时的视觉连贯性 |
| **响应式适配** | 支持桌面端大屏（1080p、2K、4K）及笔记本视口，最小可用宽度 1024px | 视口拉伸自适应测试 |
| **零破坏性升级** | 严格遵循 React 19 + Tailwind CSS v4 构建标准，`compile_applet` 一次性构建成功 | 持续集成构建验证 |
