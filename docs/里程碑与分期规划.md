| 8 | 一期 VIP 获取路径 | Admin 后台赠送 |

| 10 | 定价 | 周卡 ¥9.9 / 月卡 ¥24.9 / 年卡 **¥199** |

## 二、产品权益矩阵

| 能力 | 体验版 | VIP |
| :--- | :--- | :--- |
| 画板数量 | 最多 **3** 个 | 无限 |
| AI 推理节点 | 每画板 **10** 个 | 无限 |
| 子分支导出为独立画板 | ❌ | ✅ |
| 响应队列 | 常规 | 高优先级（更高并发限流） |
| 高级模型（`is_vip_only`） | 不可访问 | 可访问 |
| VIP 到期后 | — | 禁推理 / 禁建画板；保留只读、编辑便签、导出 |

**VIP 到期降级规则**：到期即锁定 AI 推理与新建画板，但用户必须能把自己的成果完整带走 —— 浏览、编辑便签笔记、导出 JSON 与 Markdown 大纲全部放行。已配套到期前提醒横幅与 **7 天宽限期**（`GRACE_PERIOD_DAYS=7`，宽限期内体验不中断仅提醒），避免到期瞬间锁死引发客诉。
