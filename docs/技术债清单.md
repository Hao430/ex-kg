## 持久化 / 数据 (Persistence & Data)

### #0001 双模行为漂移风险（**高**）

- **状态**: Open
- **影响**: PG 分支无测试覆盖（CODEBUDDY.md 第 20 行已自承）；内存分支与 PG 分支可能行为漂移
- **修复**:
  1. CI 增加真库冒烟（`docker-compose.pg-smoke.yml` 复用）
  2. 优先覆盖 `a3-batch-save`（事务化）、`h1-canvas-tenant-softdelete`（多租户）、`s1-data-isolation`（数据隔离）三个 spec
- **关联**: ADR-0002、报告 §13.1 P0

### #0002 全文检索语言未优化（**中**）

- **状态**: Open
- **影响**: GIN 全文检索用 `to_tsvector('simple', ...)`；中文检索分词质量差
- **修复**: 改用 `to_tsvector('jiebacfg', ...)` 或独立 Meilisearch / Elasticsearch
- **关联**: 报告 §6.3、§13.2

### #0003 JSONB 缺 GIN 索引（**低**）

- **状态**: Open
- **影响**: `messages / grounding / custom_data` JSONB 字段无 GIN 索引，复杂查询可能全表扫
- **修复**: 先量化实际查询模式（哪些字段被 `?` / `@>` 查询），再决定是否加 GIN
- **关联**: 报告 §6.3

### #0004 一期预留 8 张空壳表（**低**）

- **状态**: Open
- **影响**: `canvas_shares / canvas_snapshots / canvas_templates / tags / canvas_tags / node_attachments / user_api_keys / notifications` 8 张表已建但未启用，占用命名空间
- **修复**: 评估后决定删除或保留
- **关联**: 报告 §6.3

### #0005 ID 风格不统一（**高**，P0）

- **状态**: Open
- **影响**: `users.id` 是 UUID，`canvases / nodes / edges` 是 VARCHAR(64)；跨表 join 类型不一致
- **修复**: 二期统一为 UUID（users 已 UUID）；短期在开发规范加约束
- **关联**: 报告 §13.1 P0、ADR-0013

### #0006 `nodes.parent_id` 无环检测（**高**，P0）

- **状态**: Open
- **影响**: PG 无 CHECK 约束、代码无 cycle detection，理论可自指成环；`extractSubtree` 死循环
- **修复**:
  1. PG 加 `CHECK (id != parent_id)` 防止自指
  2. `extractSubtree` 维护 visited set 防环
- **关联**: 报告 §13.1 P0、ADR-0009

### #0007 内存 Map 单例不能跨进程（**中**）

- **状态**: Open
- **影响**: 水平扩展时内存 Map 不共享，session / rate-limit / event 都会失效
- **修复**: 水平扩展前必须先迁移到 PG（部分数据）+ Redis（session / rate-limit）
- **关联**: ADR-0002、ADR-0007

## 限流与安全 (Rate Limiting & Security)

### #0010 `trust proxy` IP 限流误判（**高**，P0）

- **状态**: Open
- **影响**: `app.set('trust proxy', 1)` 在反代/CDN 后**所有 12 个限流器对真实 IP 失效**
- **修复**:
  ```js
  app.set('trust proxy', 'loopback, linklocal, uniquelocal');
  // 或在反代入口做 IP 白名单
  ```
- **关联**: 报告 §13.1 P0、ADR-0007

### #0011 `log-cleanup` 启动时序（**高**，P0）

- **状态**: Open
- **影响**: `void run()` 在 `setInterval` 之前立即执行，不等 `initDbSchema()`；PG 启动慢时"清理假成功"
- **修复**: `run` 头部加 `await initDbSchema()` 或延后到 `app.listen` 之后
- **关联**: 报告 §13.1 P0

### #0012 `routes/subscriptions.ts` 未挂限流器（**中**，已被 arch-test 捕获）

- **状态**: Open（arch-test 已 fail 提示）
- **影响**: 攻击者可无限刷"尝试下单"消耗服务端开销
- **修复**:
  1. 在 `subscriptions.ts` 顶部加 `subscriptionRateLimiter`（IP 维度，10/min）
  2. 或加入 `arch-tests/route-rate-limiter.test.mjs` 的 `FILE_ALLOWLIST` 并写明理由
- **关联**: ADR-0007、arch-test 已自动捕获

### #0013 CSRF 防护不完整（**中**）

- **状态**: Open
- **影响**: 只靠 SameSite cookie 防御 POST；SSE 端点 + 自定义 header 应开启
- **修复**: 给 SSE 端点加 `custom header` 校验（如 `X-Requested-With`）
- **关联**: 报告 §8.3

### #0014 RLS 未启用（**高**，P0）

- **状态**: Open
- **影响**: PG 行级安全未启用；数据库直连可越权（绕过应用层属主校验）
- **修复**:
  ```sql
  ALTER TABLE canvases ENABLE ROW LEVEL SECURITY;
  CREATE POLICY canvases_owner ON canvases
    USING (user_id = current_setting('app.user_id')::uuid);
  ```
- **关联**: 报告 §13.1 P0

### #0015 管理员账号豁免注销是单点风险（**中**）

- **状态**: Open
- **影响**: 离职管理员无法通过自注销流程回收
- **修复**: 引入"超级管理员"二级角色，原始 admin 不可豁免
- **关联**: 报告 §8.3

### #0016 密码校验阻塞事件循环（**中**）

- **状态**: Open
- **影响**: scrypt 单次 ~200ms 会阻塞 Node 事件循环；登录风暴时延迟累加
- **修复**: 改用 `worker_threads` 异步执行
- **关联**: ADR-0010

### #0017 密钥管理不生产级（**中**）

- **状态**: Open
- **影响**: `GEMINI_API_KEY` / `OPENAI_API_KEY` 直接进 `.env`；生产应接 Secret Manager
- **修复**: 接入云厂商 Secret Manager（阿里云/AWS/GCP）
- **关联**: 报告 §8.3

### #0018 审计日志查询性能待优化（**低**）

- **状态**: Open
- **影响**: `user_audit_logs` 缺 `(created_at DESC)` + `(user_id, created_at DESC)` 索引，Admin 查询可能慢
- **修复**: 加复合索引
- **关联**: 报告 §8.3
